Concept 1 of 4

Combinational circuits

Outputs depend only on present inputs. There is no memory. Design procedure: read the specification, list inputs and outputs, write the truth table, derive expressions, simplify (Boolean algebra or K-map), implement, verify. Analysis runs the other way: label gate outputs, write expressions, combine, and check with a truth table.

Concept 2 of 4

Adders

Half adder: S = A ⊕ B, C = AB
Full adder: S = A ⊕ B ⊕ Cin
Cout = AB + ACin + BCin = AB + Cin(A ⊕ B)

A full adder can be built from two half adders and an OR gate. Chaining n full adders gives an n-bit ripple-carry adder: simple, but each stage waits for the carry from the one before, so delay grows with n.

Concept 3 of 4

Subtractors and the adder-subtractor

Half subtractor: D = A ⊕ B, Bout = A′B
Full subtractor: D = A ⊕ B ⊕ Bin
Bout = A′B + A′Bin + B·Bin

Hardware usually subtracts with 2’s complement: A − B = A + B′ + 1. Put an XOR gate on each B input, controlled by a mode signal M, and use M as the carry-in. M = 0 adds, M = 1 subtracts. For signed numbers, overflow occurs when the carry into the MSB differs from the carry out of the MSB.

Concept 4 of 4

BCD adder and magnitude comparator

A BCD adder is a 4-bit binary adder followed by correction logic. The largest possible sum is 9 + 9 + 1 = 19. Add 0110 when the binary sum exceeds 9 or produces a carry.

A magnitude comparator outputs A>B, A=B and A<B. For one bit: G = AB′, E = (A ⊕ B)′, L = A′B. For several bits, compare from the MSB down: the first unequal pair decides.

These blocks combine with multiplexers and logic gates to form an ALU.

Worked example 1 of 3

Worked example 1

Add 1011 + 0110 with a ripple-carry adder.
Show the solution
  1. Bit 0: 1+0 = 1, carry 0
  2. Bit 1: 1+1 = 0, carry 1
  3. Bit 2: 0+1+1 = 0, carry 1
  4. Bit 3: 1+0+1 = 0, carry 1
Result 1 0001 = 17.

Worked example 2 of 3

Worked example 2

Compute 0110 − 0011 with 2’s complement.
Show the solution
  1. Invert B: 1100, add 1: 1101.
  2. 0110 + 1101 = 1 0011.
  3. Discard the carry: 0011 = 3.

Worked example 3 of 3

Worked example 3

Add 7 + 8 in BCD.
Show the solution
  1. 0111 + 1000 = 1111 (greater than 1001).
  2. Add 0110: 1111 + 0110 = 1 0101.
  3. 0001 0101 = 15.

Summary

Summary

  • Half adder: S = A⊕B, C = AB. Full adder adds a carry-in.
  • Ripple-carry is simple but slow for wide words.
  • A − B = A + B′ + 1. XOR gates plus carry-in make an adder-subtractor.
  • Signed overflow: carry into MSB ≠ carry out of MSB.
  • BCD correction: add 0110 when the sum exceeds 9 or carries.
