Before we start

Why this matters

How does a calculator add 127 + 1 and confidently tell you the answer is −128?

That's not the calculator having a stroke — it's called overflow, and a real version of this exact bug once sent an actual rocket (Ariane 5) into an actual meltdown seconds after launch. Underneath every calculator, cash register and CPU is a circuit that only ever adds, subtracts and compares — no fingers, no muttering “carry the one” under its breath. Let's build one that behaves.

Concept

Combinational circuits

  • The outputs depend only on the present inputs.
  • There is no memory: the same inputs always give the same outputs.
  • In this chapter: adders, subtractors, comparators and BCD adders.

Design: from a specification to a circuit

Specification→Inputs and outputs→Truth table→Expressions→Simplify (algebra or K-map)→Circuit→Verify

Analysis: from a circuit back to what it does

Adder

Adding bits needs a carry

  • A binary column can only hold 0 or 1.
  • 1 + 1 = 2 does not fit, so write 0 and carry 1 into the next column on the left.
  • That carry is worth 2 here, just as a carry is worth 10 in decimal.

One bit has only four cases

0 + 0
= 0
no carry
0 + 1
= 1
no carry
1 + 0
= 1
no carry
1 + 1
= 10
write 0, carry 1

Only 1 + 1 is special. The answer needs two bits, so the second one moves to the left as the carry.

Subtractor

Subtraction needs a borrow

  • An adder carries a 1 into the next column on the left.
  • A subtractor borrows a 1 from the next column on the left.
  • A borrowed 1 is worth 2 in this column, just as a borrowed 1 is worth 10 in decimal.

One bit has only four cases

0 − 0
= 0
no borrow
1 − 0
= 1
no borrow
1 − 1
= 0
no borrow
0 − 1
= 1
borrow 1, then 2 − 1 = 1

Only 0 − 1 is special. The column is too small, so it borrows from its left neighbour.

4-bit adder

4-bit ripple-carry adder

  • Chain n full adders, one per column, to add two n-bit numbers.
  • Each Cout feeds the Cin of the column on its left. The first Cin is 0.
  • The carry must ripple through every stage before the last sum bit is ready.

So the delay grows with the width

delay
≈ n × (carry delay of one full adder)
4-bit
≈ 4 carry delays
32-bit
≈ 32 carry delays
this is why fast CPUs use carry-lookahead adders instead

Cascading comparator chips

  • The 74LS85 compares 4 bits. It also has three cascade inputs that say what the bits below it decided.
  1. Low chip compares bits 3–0. Its cascade inputs are tied to 0, 1, 0, which means “equal so far”.
  2. Its three results go into the cascade inputs of the high chip.
  3. High chip compares bits 7–4. If they differ, they decide. If they tie, it passes the low chip’s answer through.

BCD adder

BCD adder

  • Each decimal digit is stored as 4 bits, using only 0000–1001 (0–9).
  • Add two digits with an ordinary 4-bit binary adder. The largest sum is 9 + 9 + 1 = 19.
  • If the sum is above 9, add 0110 (6) to skip the six unused codes 1010–1111. That gives the right digit and a carry.

Worked example 4

Compare A = 0110 and B = 0101 using the MSB-down rule.
Show the solution
  1. Bit 3: A=0, B=0 — tie, move to the next bit down.
  2. Bit 2: A=1, B=1 — tie, move to the next bit down.
  3. Bit 1: A=1, B=0 — they differ, and A's bit is the larger one.
The first pair that differs, scanning from the MSB, decides it: A > B (6 > 5). Bit 0 is never even examined.

Worked example 5

Add the two-digit BCD numbers 47 + 38, correcting each decimal digit and carrying into the next.
Show the solution
  1. Units digit: 0111 (7) + 1000 (8) = 1111 (15), which is > 9, so add 0110: 1111 + 0110 = 1 0101 — units digit 0101 (5), carry 1 into the tens digit.
  2. Tens digit: 0100 (4) + 0011 (3) + carry-in 1 = 1000 (8), which is ≤ 9, so no correction is needed — tens digit 1000 (8).

Summary

Summary

  • Half adder: S = A⊕B, C = AB. Full adder adds a carry-in.
  • Ripple-carry is simple but slow for wide words.
  • Half subtractor: D = A⊕B, Bout = A′B. Full subtractor adds a borrow-in: D = A⊕B⊕Bin, Bout = A′B + A′Bin + B·Bin.
  • A − B = A + B′ + 1. XOR gates plus carry-in make an adder-subtractor.
  • Signed overflow: carry into MSB ≠ carry out of MSB.
  • Comparator: scan from the MSB down; the first bit pair that differs decides. A = B needs every pair equal.
  • BCD correction: add 0110 when the sum exceeds 9 or carries.
