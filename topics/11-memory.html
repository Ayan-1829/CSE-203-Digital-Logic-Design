Concept 1 of 4

Memory organisation

Memory stores binary words at numbered addresses. It is described as words × bits per word: 1K × 8 means 1024 words of 8 bits. n address lines select 2n locations. Data lines carry the word to or from memory.

  • Read: apply the address, enable the memory, activate read, and the word appears on the data lines.
  • Write: apply address and data, enable the memory, activate write, and the word is stored.
capacity = 2ⁿ words × m bits
10 address lines, 8 data lines: 1024 × 8 = 8192 bits = 1 KB

Concept 2 of 4

RAM: SRAM and DRAM

Random-access memory can be read and written at any address in the same time. SRAM uses bistable cells, needs no refresh and is fast. DRAM stores charge in a capacitor, so it must be refreshed periodically, but it is much denser and is used for main memory. Both lose their contents without power.

Concept 3 of 4

Address decoding and expansion

A decoder turns address bits into a select line for a location or a chip. A chip select input enables only the chip being addressed. Many chips share one tri-state data bus, and only the selected chip drives it.

  • Word expansion adds locations: extra high address bits feed a decoder that drives the chip selects.
  • Bit expansion widens the word: chips share the address lines and their data lines side by side (two 4-bit chips make an 8-bit word).

A memory map lists which address range belongs to which device.

Concept 4 of 4

Error detection and correction

A parity bit detects any single-bit error but cannot say which bit. A Hamming code places check bits at the power-of-two positions (1, 2, 4, …). Recomputing the checks after a read gives a syndrome, which is the position of a single wrong bit, so it can be flipped back. Adding one overall parity bit gives SEC-DED: single-error correction and double-error detection.

Show the solution
  1. 212 = 4096 locations.

Worked example 2 of 2

Worked example 2

Build a 4K × 8 memory from 1K × 8 chips.
Show the solution
  1. Chips needed: 4K / 1K = 4.
  2. Address lines: 12. The low 10 go to every chip. The top 2 feed a 2-to-4 decoder that drives the four chip selects.

Summary

Summary

  • n address lines select 2n locations.
  • SRAM: fast, no refresh. DRAM: dense, needs refresh.
  • Decoders and chip selects choose the active device.
  • Word expansion adds locations, bit expansion adds width.
  • SEC-DED corrects one error and detects two.
