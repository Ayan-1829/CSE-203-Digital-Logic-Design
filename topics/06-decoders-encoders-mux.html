Concept 1 of 4

Decoders

An n-to-2n decoder turns an n-bit code into one active output line. Each output is a minterm of the inputs. For a 2-to-4 decoder: Y0 = A′B′, Y1 = A′B, Y2 = AB′, Y3 = AB.

An enable input switches the whole decoder on or off. Enable lets you build big decoders from small ones: a 3-to-8 decoder is two 2-to-4 decoders, with the third input bit driving the enables. Since a decoder makes every minterm, any function is an OR of its output lines. A full adder needs one 3-to-8 decoder and two OR gates. Decoders also drive memory address selection and displays.

Concept 2 of 4

Encoders

An encoder does the reverse: one active input becomes a binary code. A 4-to-2 encoder has A = D2 + D3 and B = D1 + D3. An octal-to-binary encoder has A2 = D4+D5+D6+D7, A1 = D2+D3+D6+D7, A0 = D1+D3+D5+D7.

A basic encoder assumes only one input is active. A priority encoder allows several and outputs the code of the highest-priority one, plus a valid flag V that says whether any input is active.

Concept 3 of 4

Multiplexers

A multiplexer (MUX) is a data selector: 2n data inputs, n select lines and one output.

2-to-1: Y = S′·I0 + S·I1
4-to-1: Y = S1′S0′I0 + S1′S0 I1 + S1 S0′ I2 + S1 S0 I3

A MUX can generate any function. Feed n−1 of the variables to the select lines and connect each data input to 0, 1, the last variable, or its complement.

Concept 4 of 4

Demultiplexers

A demultiplexer (DEMUX) sends one input to one of 2n outputs chosen by the select lines. A decoder with an enable input works as a DEMUX: use the enable as the data input. A 1×8 DEMUX can be built from a 1×2 DEMUX in front of two 1×4 DEMUXes, with the top select bit choosing which 1×4 receives the data.

Worked example 1 of 2

Worked example 1

Implement F(A,B,C) = Σm(1,2,6,7) with a 4-to-1 MUX (A and B on the select lines).
Show the solution
  1. AB = 00: F = 0 when C = 0 and 1 when C = 1, so I0 = C.
  2. AB = 01: F = 1 when C = 0 and 0 when C = 1, so I1 = C′.
  3. AB = 10: F = 0 for both, so I2 = 0.
  4. AB = 11: F = 1 for both, so I3 = 1.

Worked example 2 of 2

Worked example 2

Build a 3-to-8 decoder from two 2-to-4 decoders.
Show the solution
  1. Connect B and C to both decoders’ inputs.
  2. Drive the enable of the first with A′ (outputs Y0–Y3) and of the second with A (outputs Y4–Y7).

Summary

Summary

  • A decoder makes all minterms of its inputs.
  • An encoder is the reverse. Priority encoders resolve multiple active inputs.
  • A MUX is a data selector. 2-to-1: Y = S′I0 + S·I1.
  • Any function fits a MUX with data inputs from {0, 1, X, X′}.
  • A decoder with enable is a DEMUX.
