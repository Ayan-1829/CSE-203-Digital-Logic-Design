Concept 1 of 4

Register structure and control

An n-bit register is n flip-flops sharing a clock, each storing one bit. Common controls: clear (force 0), load (accept new data), enable (allow change). With load = 1 the register accepts data on the next clock edge, and with load = 0 it holds. Operations: load, clear, hold, shift, transfer. In parallel load all bits enter in the same clock cycle.

Concept 2 of 4

Shift registers

A shift register moves its bits one place per clock. Shift left moves bits toward the MSB and a new bit enters at the right. Shift right moves toward the LSB and a new bit enters at the left. The four styles:

TypeInOutUse
SISOSerialSerialDelay lines
SIPOSerialParallelSerial to parallel conversion
PISOParallelSerialParallel to serial conversion
PIPOParallelParallelStorage, buffering

A bidirectional register shifts either way under a direction control. A universal shift register supports hold, shift left, shift right and parallel load, usually with a 4-to-1 MUX at each flip-flop input.

Concept 3 of 4

Register transfer language

RTL describes data movement between registers. R2 ← R1 copies R1 into R2. R1 ← R1 + 1 increments. R3 ← R1 AND R2 stores a logic result. A control condition can guard a transfer: P: R2 ← R1 happens only when P = 1.

Concept 4 of 4

Registers in CPUs

CPUs use registers for operands, addresses, instructions and status: general-purpose registers, the program counter, the instruction register and the status register. A register file holds several registers, and selected ones feed the ALU. Registers are very fast and small. Main memory has more capacity and is slower.

Summary

Summary

  • A register is n flip-flops with a shared clock.
  • Controls: clear, load, enable. Load = 0 means hold.
  • SISO, SIPO, PISO, PIPO describe serial or parallel in and out.
  • RTL: R2 ← R1 copies a register.
  • Registers are fast and small compared with memory.
