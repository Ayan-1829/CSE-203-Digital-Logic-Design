Viva questions

1. Why are NAND and NOR universal gates?
Show a model answer
Each can build NOT (tie the inputs), and then AND and OR by DeMorgan’s laws, so any function can be built from one gate type.
2. When is a K-map useful?
Show a model answer
For simplifying functions of two to four variables (up to about six with care), because it shows adjacent minterms visually and gives minimal SOP or POS.
3. Combinational vs. sequential?
Show a model answer
Combinational outputs depend only on present inputs. Sequential outputs also depend on stored state.
4. Why are flip-flops clocked?
Show a model answer
The clock makes every state change happen at one known instant, which makes timing predictable and avoids races.
5. Decoder vs. encoder?
Show a model answer
A decoder turns a binary code into one active line. An encoder turns one active line into a binary code.
6. How can a MUX implement a Boolean function?
Show a model answer
Use the variables as select lines and connect the data inputs to the function values (constants, or the leftover variable and its complement).
7. How is the flip-flop count for a MOD-N counter found?
Show a model answer
The smallest n with 2ⁿ ≥ N.
8. Why is state reduction useful?
Show a model answer
Merging equivalent states can save flip-flops and combinational logic without changing the external behaviour.
9. How does memory decoding work?
Show a model answer
A decoder converts address bits into a single select line for a location or chip, and chip selects enable only the addressed device.
10. What are PLA and PAL?
Show a model answer
Programmable logic devices with an AND array and an OR array. In a PLA both are programmable. In a PAL only the AND array is.
