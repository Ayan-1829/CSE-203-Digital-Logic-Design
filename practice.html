1. Introduction to Digital Logic
1. Classify each as combinational or sequential: a 4-bit adder, a counter, a decoder, a register.
Show the answer
Adder and decoder are combinational. Counter and register are sequential because they store state.
2. Write the truth table of a 2-input AND gate.
Show the answer
00 → 0, 01 → 0, 10 → 0, 11 → 1.
3. Give two reasons digital systems tolerate noise better than analog ones.
Show the answer
Signals are read against thresholds, so small deviations decode to the same bit, and a noisy signal can be regenerated to clean levels.
4. How many bits are needed to label 100 different items?
Show the answer
7 bits, because 26 = 64 is too small and 27 = 128 is enough.

45
2. Find the 2’s complement of 00101101.
Show the answer

3. Write 59 in BCD.

3. Boolean Algebra & Logic Gates
1. Simplify A + AB.
Show the answer
A, by absorption.
2. Apply DeMorgan to (AB + C)′.
Show the answer
(A′ + B′)C′
3. A 2-input function is 1 only for inputs 01 and 10. Write its canonical SOP and POS.
Show the answer
SOP: A′B + AB′ = Σm(1,2). POS: (A+B)(A′+B′) = ΠM(0,3). This is XOR.
4. Write the dual of A + BC′.
Show the answer
A(B + C′)
4. Universal Gates & Karnaugh Maps
1. Build NOT, AND and OR using only NAND gates.
Show the answer
NOT: tie both inputs. AND: NAND then NOT. OR: NAND(A′, B′) where each input is first inverted by a NAND.
2. Build NOT, OR and AND using only NOR gates.
Show the answer
NOT: tie both inputs. OR: NOR then NOT. AND: NOR(A′, B′).
3. Simplify F(A,B,C) = Σm(0,1,2,5,6,7).
Show the answer
A′B′ + BC′ + AC (or A′C′ + B′C + AB). Both have three terms.
4. Simplify F(A,B,C,D) = Σm(1,3,5,7,9) + d(11,13,15).
Show the answer
D. Every odd cell is 1 or X, so one group of eight covers them.
5. Simplify F(A,B,C,D) = Σm(0,1,2,4,5,6,8,9,12,13,14).
Show the answer
C′ + A′D′ + BD′
5. Combinational Logic & Arithmetic Circuits
1. Derive the half adder equations.
Show the answer
S = A ⊕ B, C = AB.
2. How do you build a full adder from half adders?
Show the answer
The first half adder adds A and B. The second adds that sum and Cin. OR the two carry outputs to get Cout.
3. Derive the half subtractor equations.
Show the answer
D = A ⊕ B, Borrow = A′B.
4. Explain ripple-carry delay.
Show the answer
Each stage must wait for the carry from the previous stage, so total delay is roughly n times the carry delay of one full adder.
5. Perform the BCD addition 7 + 8.
Show the answer
0001 0101 (15).
6. Design a 1-bit magnitude comparator.
Show the answer
G = AB′, E = A XNOR B, L = A′B.
6. Decoders, Encoders & Data Selectors
1. Design a 2-to-4 decoder.
Show the answer
Y0 = A′B′, Y1 = A′B, Y2 = AB′, Y3 = AB (four AND gates and two inverters).
2. Design a 4-to-2 encoder.
Show the answer
A = D2 + D3, B = D1 + D3 (assuming one active input).
3. Write the equation of a 2-to-1 MUX.
Show the answer
Y = S′·I0 + S·I1
4. Explain priority encoding.
Show the answer
When several inputs are 1, the encoder outputs the code of the highest-priority one, and a valid bit shows whether any input is active.
5. Compare MUX and DEMUX.
Show the answer
MUX selects one of many inputs for one output. DEMUX routes one input to one of many outputs.
7. Sequential Logic: Latches & Flip-Flops
1. Explain the difference between a latch and a flip-flop.
Show the answer
A latch is level-sensitive: it follows its inputs while enabled. A flip-flop is edge-triggered: it samples inputs only at a clock edge.
2. Draw an SR latch.
Show the answer
Two NOR gates. The output of each feeds one input of the other. The free inputs are R (for Q) and S (for Q′).
3. Explain D flip-flop operation.
Show the answer
At the active clock edge, Q takes the value of D. Between edges Q holds.
4. Compare JK and T flip-flops.
Show the answer
A T flip-flop is a JK with J and K tied together. T = 0 holds, T = 1 toggles.
5. Explain rising-edge triggering.
Show the answer
The flip-flop looks at its inputs only at the instant the clock goes from 0 to 1 and ignores changes at other times.
8. State Machines & Sequential Circuit Design
1. Convert a state diagram into a state table.
Show the answer
For each state and each input value, write the next state and the output. One row per (state, input) pair.
2. How do you identify equivalent states?
Show the answer
Compare rows: same outputs for every input, and next states that are the same or themselves equivalent.
3. How many flip-flops for 10 states?
Show the answer
4

9. Counters
1. Design a 3-bit ripple counter.
Show the answer
Three T flip-flops with T = 1. Clock the first, and connect Q′ of each stage to the clock of the next (for positive-edge flip-flops). Try the circuit below.
2. Compare ripple and synchronous counters.
Show the answer
Ripple: clock passes stage to stage, simple, accumulating delay. Synchronous: common clock, faster, needs extra gates.
3. Design an up/down counter.
Show the answer
Add a control input. For stage k use Tk = (Q0·…·Qk−1)·UP + (Q0′·…·Qk−1′)·DOWN, with T0 = 1.
4. How many flip-flops for a MOD-12 counter?
Show the answer
4
5. Explain ring and Johnson counters.
Show the answer
A ring counter circulates one 1 (n states). A Johnson counter feeds back the complement of the last stage (2n states).
10. Registers
1. Design a 4-bit SISO register.
Show the answer
Four D flip-flops in a chain: Q of each feeds D of the next, one common clock. Try the shift register circuit.
2. Explain SIPO and PISO.
Show the answer
SIPO takes serial data in and presents all bits in parallel. PISO loads all bits in parallel and shifts them out serially.
3. What is the purpose of Load?
Show the answer
Load = 1 accepts new data at the clock edge. Load = 0 keeps the current value.
4. Demonstrate four right shifts.
Show the answer
See the example above, or use the simulator.
5. Write RTL for register transfers.
Show the answer
R2 ← R1, R1 ← R1 + 1, R3 ← R1 AND R2.
11. Memory & Error Correction
1. How many locations can 12 address lines select?
Show the answer
4096
2. Calculate the capacity of a 2K × 8 memory.
Show the answer
16384 bits, which is 2 KB.
3. Explain address decoding.
Show the answer
A decoder converts the address bits into one select line, which activates the addressed location or chip.
4. Design a 3-to-8 decoder-based selection system.
Show the answer
The top three address bits drive a 3-to-8 decoder. Each output is the chip select of one of eight memory chips.
5. Distinguish word expansion from bit expansion.
Show the answer
Word expansion increases the number of locations and needs decoding. Bit expansion widens the word by putting chips in parallel.
12. ROM & Programmable Logic
1. Explain ROM organization.
Show the answer
Address lines feed a decoder. Each decoder output selects one stored word, and the OR gates present that word’s bits at the outputs.
2. Compare PROM, EPROM, EEPROM and Flash.
Show the answer
PROM: programmed once. EPROM: UV erase. EEPROM: electrical erase by byte. Flash: electrical erase in blocks.
3. Describe the PLA architecture.
Show the answer
Inputs and their complements feed a programmable AND array (product terms), which feeds a programmable OR array (outputs).
4. Compare PLA and PAL.
Show the answer
PLA: both arrays programmable. PAL: only the AND array is programmable.
5. Implement F = AB + A′C with programmable logic.
Show the answer
Two product terms, AB and A′C, both connected to the OR gate of the output.
