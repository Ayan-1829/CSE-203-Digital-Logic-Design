Concept 2 of 4

Inside a CPU

A CPU has a datapath (registers, ALU, buses) and a control unit. The control unit is a finite state machine that decodes instructions and coordinates the datapath. The CPU talks to memory over an address bus, a data bus and a control bus. A 4-bit ALU combines an adder-subtractor and logic gates, with select lines that choose the result through multiplexers.

Concept 3 of 4

Example systems

  • Traffic light: an FSM with states for each light combination and a counter that times each state.
  • Digital lock: an FSM that tracks a button sequence and unlocks when the correct one is detected.
  • Vending machine: states record accumulated credit, inputs are coins, outputs release product or change.
  • Digital clock: counters divide the clock frequency, registers hold digits, decoders drive displays.

Concept 4 of 4

Troubleshooting checklist

  1. Clock assumptions: edge, frequency, is it running?
  2. Input values and switch positions.
  3. Truth table or state table against the circuit.
  4. Gate connections and pin numbers.
  5. Reset and initial state.
  6. Timing: setup, hold, and every state transition.

Worked example 1

How many AND gates make the partial products of a 3×3 multiplier?
Show the solution
  1. Each of the 3 bits of B multiplies each of the 3 bits of A.
  2. 3 × 3 = 9 AND gates.
  3. Adders then sum the shifted rows into a 6-bit product.

Worked example 2 of 2

Worked example 2

How many flip-flops does the traffic light controller in the demo need?
Show the solution
  1. Four states (NS green, NS yellow, EW green, EW yellow).
  2. ⌈log₂4⌉ = 2 flip-flops, plus a counter for timing.

Summary

Summary

  • Complex systems are built by combining simple blocks.
  • A CPU is a datapath plus a control unit connected to memory by buses.
  • FSMs make controllers such as traffic lights and locks.
  • Follow the workflow: specify, model, simplify, implement, verify.
  • Troubleshoot clock, inputs, connections, reset and timing.
